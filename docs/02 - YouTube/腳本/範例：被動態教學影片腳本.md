# 🎬 【會考必考】被動態一次搞懂！

## 🎯 目標觀眾

- 國三會考生
- 對被動態混淆的學生

## 📝 腳本大綱

### 開場（0:00 - 0:45）

- 會考必考文法 TOP3，被動態一定上榜
- 一個公式秒懂被動態：be + p.p.

### 主動 vs 被動（0:45 - 3:00）

| 主動 | 被動 |
|------|------|
| The cat ate the fish. | The fish **was eaten** by the cat. |
| 貓吃魚（主詞做動作） | 魚被吃（受詞變主詞） |

### 各時態的被動變化（3:00 - 6:00）

- 現在簡單：is/am/are + p.p.
- 過去簡單：was/were + p.p.
- 未來簡單：will be + p.p.
- 現在完成：have/has been + p.p.

### 會考陷阱題（6:00 - 8:30）

- 沒有 by 的被動式
- 感官動詞 + 被動用法
- need + V-ing = need to be + p.p.
